# 山寺 · sansa-clone

照着 [sansatemple.com](https://sansatemple.com/) 的玩法重做的一座线上寺院，
建筑和人物按汉传佛寺来做：大家各是一个穿黄海青、披红袈裟的 Q 版小沙弥，
在同一座寺里散步、合十、去大雄宝殿的蒲团上礼佛、敲木鱼、拨 108 颗念珠、
坐石凳、上香、撞钟击鼓，彼此看得见但不聊天。

代码、贴图和声音全部是新写的，没有使用原站的任何素材；佛像用的是公开授权的博物馆扫描模型（见「素材来源」）。

## 运行

```bash
npm install --include=dev      # 本机 NODE_ENV=production，要显式装开发依赖
npm run build                  # 生成 dist/
npm start                      # node server/server.mjs → http://127.0.0.1:4318
```

开发时可以两个终端分别跑 `npm run server` 和 `npm run dev`（Vite 在 4317 端口，
`/ws`、`/api` 自动代理到 4318）。

环境变量：`PORT`（默认 4318）、`HOST`（默认 127.0.0.1，对外部署改成 0.0.0.0）。

链接参数：`?lang=zh|ko|ja|en` 切换语言，`?time=dawn|day|dusk|night` 固定时段，
`?room=1..5` 进入指定服务器。
调试用：`?svc=秒数` 把寺里的时刻表拨到当前小时的第几秒（如 `?svc=70` 直接看共修）。
下面几个要和 `?debugview` 一起用：`?routine=秒数` 把僧人的日常拨到一轮里的第几秒（如 `?routine=70` 看小沙弥奉茶），
`?say=elder` 让某位僧人开口，`?hideme` 截图时隐藏自己。

## 玩法：功德、修行等级与寺务

放松玩法，不会失败，但每件事都要自己动手，做得好功德多：

- **功德点与修行等级**：礼佛、上香、撞钟、击鼓、放河灯、喂鱼、求签、念满一圈念珠、参加整点共修都有功德点，头顶飘「功德 +N」。攒够了升级：居士 → 行者 → 沙弥 → 比丘 → 法师 → 禅师 → 长老，称号显示在自己的名牌上。
- **木鱼是节奏游戏**：木鱼外有一圈会收拢的光环，收到木鱼上那一刻敲下去是「妙」，差一点是「好」，偏了不计连击；连击 10 下、30 下以上每下多得功德。自动敲只计数、不计功德点。
- **撞钟要自己拉**：走到钟旁按住（鼠标、手指或空格）把撞木往后拉，力度条来回摆，落在金色区间松手最好，钟声更洪亮，屏幕上显示「钟声传出几里」。
- **寺务**：头上有「！」的僧人有事找你，点他接活。扫地僧请你扫银杏下三堆落叶，小沙弥请你给三棵树浇水；点落叶堆或树下的浅色圈就去做，做完回去回禀拿谢礼。每天本地零点重置。左上角显示当前寺务进度。

调试（与 `?debugview` 一起用）：`&moktak=9` 打开木鱼按拍敲 9 下，`&do=bell` 直接去撞钟，`&quest=sweep|water` 直接接寺务，再加 `&qauto` 自动做完并回禀。

## 随修行解锁的地方与衣钵

右上角莲花图标是「修行」面板：当前称号和到下一级的功德进度、每一级开放什么、衣钵（换僧袍和念珠）。

| 等级 | 功德 | 开放 |
|---|---|---|
| 行者 | 60 | 观音殿、灰海青·褐袈裟 |
| 沙弥 | 200 | 地藏殿、菩提子念珠 |
| 比丘 | 500 | 藏经阁（抄经）、金黄袈裟、星月菩提 |
| 法师 | 1200 | 登塔、金线袈裟 |
| 禅师 | 3000 | 茶褐衣、蜜蜡念珠 |
| 长老 | 8000 | 紫金袈裟、珊瑚念珠 |

衣钵存在本地（`sansa.look`），联机时随位置一起发出（`僧袍.念珠.等级`），别人看到你的僧袍颜色，名牌上带称号。

- **登塔**：点双塔任一座，走到朝中轴线的塔门，黑一下就到了顶层檐下；拖动环顾，院子里和山谷里升起云海（镜头高过 6 米才显出来，开场画面也看得到），殿顶、树冠从云里露出来。点「下塔」回到塔门前。每天第一次登塔给功德。
- **藏经阁**：大殿正后方的两层楼阁（后院墙因此往后挪到 z = -50）。殿里一排排经橱，三张经案。点经案坐下抄《心经》，有两种写法，进度共用（右上角切换，记在 `sansa.sutra.mode`）：
  - **键盘**（电脑默认）：铺开一整张朱丝栏经纸（右起一列经题，十三字一列，二十列正好一部），用平常的输入法打出灰色的字，打对一个就在纸上落一个带点歪斜和浓淡的墨字；简体、日文新字形都认（观＝觀、仏＝佛），标点不用打，打错了那一格抖一下。输入框藏在当前格上，输入法的候选框就出现在格子旁边，正在拼的拼音显示在格子左边。屏幕窄时分几页。每字 1 功德。
  - **毛笔**（手机默认）：照着米字格里的灰色楷字描，覆盖够了自动换下一字，按描得贴不贴合评「妙 / 好 / 成」，每字 2–4 功德。

  抄完一句 +5，抄完全经（260 字）+100；进度存在本地（`sansa.sutra`）。每抄一字，自己的墨迹缩成小图存下（`sansa.sutra.ink`，键盘打的记 `k`，拼横幅时用字体写）；纸面右上角的卷轴按钮把它们拼成一张横幅（右起经题，正文二十列每列十三字，没抄的字是淡灰的范字，左边落款「名字 敬書」、日期和「心經」朱印），可以存成图片；抄完全经时自动打开。殿里有一位知藏师：在门边的垫子上读经，隔一会儿起身擦理经橱（藏经阁没开放时不露面）。

调试：`&points=600` 加功德，`&panel=practice` 打开修行面板，`&look=crimson.amber` 换衣钵，`&climb=0` 直接登左塔，`&desk=1` 去中间的经案抄经，再加 `&sutraauto=6` 自动描 6 个字（再加 `&sutrascroll` 描完打开横幅），`&sutramode=type|brush` 指定写法，`&sutratype=观自在` 模拟键盘打一段，`&seat=c7` 直接坐上大殿的蒲团。

### 养成：修行进度、今日功课、经藏

- **左上角常驻**一条：称号、到下一级的功德进度条、今日功课完成几项。点它打开「修行」面板（右上角莲花图标也能打开）。
- **修行面板四页**：
  - 「进度」：称号与功德、今日功课（每项一条进度条，「去做」直接带你去）、修行之路；
  - 「经藏」：六部经的开放等级、读过几遍、这一遍读到百分之几；
  - 「规则」：每件事给多少功德；
  - 「衣钵」：换僧袍和念珠。
- **今日功课**（`progress.ts` 的 `DAILY`，每天本地零点重置）：礼佛十拜、上一炷香、木鱼三十下、念珠一圈、读经三页、喝完一杯山寺咖啡、抄经五字（藏经阁开放后才有）。每项做满自动给 5～8 功德，全部做完再给 20。
- **经藏**（`src/reader.ts`）：《心經》一开始就能读，之后行者开《八大人覺經》、沙弥开《阿彌陀經》、比丘开《普門品》、法师开《四十二章經》、禅师开《金剛經》。
  - 按屏幕宽窄分页，逗号处也可以翻页；繁体、简体可切换。
  - 一页停留 5 秒算读过：每页每天第一次给 1 功德（每天前 40 页），读完一部给 10，第一次读完给 30；记「读过几遍」，下次打开从上次的页接着读。
  - 点藏经阁后墙的经橱也能打开经藏。
- **经文来源**：维基文库整理的古代译本（公有领域）。用 `python3 -I tools/build-sutras.py <维基文库 API 的 JSON 目录> public/sutras` 生成，需要 `opencc-python-reimplemented` 做繁转简。

调试：`&panel=practice&ptab=sutras|rules|look` 打开修行面板的某一页，`&read=pumen` 直接打开某部经（编号：heart、eight、amitabha、pumen、forty2、diamond）。

### 山寺咖啡

东院一座三开间的茶寮（`src/world/cafe.ts`，位置和尺寸在 `layout.ts` 的 `CAFE`）：厅宽 11 米、深 6.4 米，朱红柱、灰瓦四坡顶，檐下「山寺咖啡」金匾，中间两根前柱挂对联「一盞清香消俗慮 / 半窗山色入禪心」。厅里后墙前一整排 7.6 米的吧台：咖啡机、两台磨豆机、三杯手冲架、点心柜（桂花糕、素月饼、柿饼），墙上三块菜单牌（咖啡、手冲云南豆、茶点），三盏竹编吊灯；两侧山墙开格子窗，窗边各一张小桌。厅前一片 5 米深的木平台，四张小圆桌各撑一把油纸伞，两角竹盆；平台左前角竹竿挑「咖啡」布幌子，右前角一只大纸杯回收桶，入口旁立菜单木牌。一共 6 张桌 12 只圆凳（`k0`–`k11`，可以坐）。吧台后两位咖啡师父，一位跑堂小沙弥端托盘给露台送咖啡、收拾桌子。夜里前檐一排纸灯笼和厅里的暖光亮起来。

- **点单**：点茶寮、菜单牌或咖啡师父，走到柜台前打开纸菜单（`src/coffee.ts`）：般若拿铁、菩提美式、上岸冷萃、桂花拿铁、放下·低因。点一杯等 6.5 秒（磨豆、萃取的声音，机器冒热气），杯子端在右手上。
- **喝**：右下角的杯子条「喝一口」，一杯三口；喝完一句收尾的话，算今日功课「喝完一杯山寺咖啡」（+4）。
- **请人喝**：端着满杯时点常住僧人或别的访客，走过去双手递上（+8 功德）；僧人会道谢，访客手里多一杯，会收到「某某请你喝了一杯……」。联机时服务器核对：自己是满杯、对方空着手、两人相距 3.5 米内。
- **空杯**：点回收桶（或杯子条上的「去回收」）放进去（+1，惜福）。喝过的不能请人，没喝完的不能扔。
- **分享卡**：杯子条上的分享按钮生成一张 1080×1440 的竖图（画出来的杯子、饮品名、一句话、落款和印），可以写一句话再存下来。
- 联机时手里的杯子随位置一起发出（`饮品.还剩几口`），别人看得到你端着什么、看得到你喝。

调试（与 `?debugview` 一起用）：`&do=cafe` 走去点单，`&brew=latte` 走去直接做一杯，`&coffee=coldbrew&sips=2` 直接端上一杯，`&sipnow=3000` / `&offernow=3000` 过几毫秒做一次喝、递的动作。

### 西院：祈福灯廊、柿饼架；石板小路、草丛和野花

- **祈福灯廊**（`src/world/garden.ts`，位置在 `layout.ts` 的 `WISH_ALLEY`）：西院一条南北向的廊子，两排高木杆，杆间拉横绳、交叉的斜绳和两边的顺绳，挂着约 150 盏各色灯笼（实例化绘制，轻轻晃，夜里亮暖黄的光）。访客挂的那盏下面吊一张心愿纸签，自己的是金色的；没人挂的位置由寺里挂素灯笼，廊子总是满的。廊子里镜头压在灯笼底下。
- **挂一盏**：点灯廊东边的祈福台（或木杆）走过去，选类别（平安、上岸、健康、暴富、脱单、顺遂、家人）、选灯笼颜色、写一句（24 字以内，不写就用类别的默认一句），「挂上去」：走到那盏灯底下，双手举起，灯从手里升到绳上（+5 功德）。每天一盏（`sansa.wishDay`）。
- **看心愿**：点任一盏有纸签的灯，弹出一张竖签：类别、心愿、谁挂的、日期；可以「随喜」（+1 功德，每盏一次）或举报（自己不再看到；两人举报就从服务器撤下）。
- **服务器**：心愿所有房间共用一份，存在内存里，挂七天，最多 240 条；不收网址和七位以上的数字串；每个连接十分钟内只能挂一盏。自己挂的也存在本地（`sansa.wishes`），服务器重启后再进来会自动补交（每个连接一次、最多三条）。挂点按心愿编号计算，新心愿不会把别人的灯挤走。
- **柿饼架**（`PERSIMMON`）：灯廊北头，两排木架挂着一串串柿子，竹篮里放着新摘的柿子，旁边立着「柿柿如意」木牌。点它走过去合十，飘一句「好柿成双」「心想柿成」之类的祝福，每天第一次 +3 功德。
- **石板小路**：从参道两侧分出去，东边通到咖啡摊、西边通到祈福台（`STONE_PATHS`，只是铺地，不挡路）。前院两侧、墙根、树下散着一丛丛偏黄的秋草，有些开着波斯菊、小雏菊（手机上数量减半）。
- 咖啡摊的空杯回收桶改成一只半人高的大纸杯，杯套上印「山寺咖啡 · 空杯回收」。

调试（与 `?debugview` 一起用）：`&do=wish` 走去祈福台写心愿，`&do=persimmon` 去柿饼架，`&wishdemo=80` 在本机挂 80 盏假心愿看效果（再加 `&readwish` 打开第一盏的心愿），`&hang=愿一战上岸` 直接走去挂一盏。

### 配殿

院子两侧的观音殿、地藏殿起初关着门，点殿门会提示还差多少功德。修行到「行者」开观音殿，到「沙弥」开地藏殿，殿门会转开，殿里点起暖灯：

- **观音殿**：供宋代水月观音。点佛坛去「礼观音」，合十后得一句祝福（30 秒内重复礼拜不再给功德）。
- **地藏殿**：供地藏菩萨，佛坛旁一架三层三十六盏的长明灯。点灯架去点灯，一次一盏，当天累计，夜里一片暖光。

调试：`?debugview&points=300` 直接加功德点看解锁，`&lamps=24` 直接点亮长明灯。

## 寺里的人与时刻表

寺里常住十一位僧人，穿灰褐海青（老和尚穿黄袍、搭袈裟，小沙弥穿浅灰、个子小一圈）。
平时各忙各的，手里拿着做事用的东西；走近时头顶写着职名和正在做的事（如「小沙弥 · 浇树」），
你在旁边时他们偶尔自言自语一句；点他们会说一句话。站着没事的僧人，你走到跟前会转过来看你。
这些日常也按服务器时间循环，所有人看到的位置和动作一样：

| 僧人 | 平时在做什么 |
|---|---|
| 知客僧 | 山门内迎客，有人走近就转身合十；隔一阵走到桥头朝山门合十，再去河灯台把灯摆整齐 |
| 扫地僧 | 在前院绕圈，走一段停下扫一会儿；扫完一圈到东边银杏下的石凳歇脚喝茶 |
| 老和尚 | 西边银杏下蒲团上打坐；小沙弥端茶来时接过来喝，给小沙弥讲几句，之后起身绕树散步 |
| 小沙弥（甲） | 提铜喷壶到放生池边跪下打水，挨棵给银杏、枫树浇水，浇完再回池边打水 |
| 小沙弥（乙） | 从观音殿端茶给老和尚，坐下听讲；再去池边喂鱼（锦鲤会游过来），然后到石凳上读经 |
| 香灯师 | 守在佛前木鱼旁；不共修时去佛前和院中大香炉上香，把香炉擦一遍，理一理两边烛台 |
| 维那 | 守在佛前引磬旁；不共修时沿殿里绕到殿门口，站着看一会儿院子再回来 |
| 钟头、鼓头 | 按时撞钟、击鼓；其余时间在楼上扫地，鼓头还会把鼓擦一擦 |
| 绕塔僧（两位） | 拨着念珠各绕东西一座塔，塔在右手边，每圈在塔前合十 |

时刻表按服务器时间走，所有人看到的是同一场：

- 每个整点：钟楼撞钟三下，四位僧人从配殿走进大殿；
- 整点后约 1 至 5 分钟：大殿共修，僧人齐拜，念佛声离大殿越近越响；屏幕上方出现「大殿正在共修 · 去礼佛」，点按钮会走到空蒲团跪拜，跟着拜一次记一次「共修」功德；
- 共修结束僧人退回配殿；每小时的半点鼓楼击鼓九下。

共修时点右上角的念佛按钮，这一场的念佛声就静音了。

时间跟随本地时钟：清晨、白天、傍晚、夜晚光线不同。入夜后红灯笼、宫灯、配殿门窗、石灯和塔灯会亮，放生池上有寺里放的莲花河灯，岸边有萤火虫；白天有燕子和蝴蝶。

打开网页先是开场标题，点「入山门」进寺（同时打开声音）。链接带 `?nointro` 可以跳过开场。

画面走写实路线：
- 天空按太阳位置做大气散射（three.js 的 Sky，自带会飘的云），环境光也由这片天空生成，早晚光色随时间变；

- 院里的银杏、枫树、松树用 ez-tree 长出写实枝叶，随风轻摆；
- 人物仍是 Q 版小和尚；真实比例的身体（约 1.68 米，海青、宽袖袖兜、能弯的手肘膝盖、人头扫描）保留在 src/body-real.ts，网址加 `?real` 可以看；

- 后期：环境光遮蔽（墙角、檐下自然变暗）、泛光（只给灯火）、色调映射与按时段调色。帧率长期偏低时会自动降分辨率、再不行关掉泛光；设置里的「画质」可以直接选「流畅」。手机上树和远景林子会自动减量。

## 宣传片

`tools/promo/` 用游戏本身的场景逐帧录一支竖屏宣传片（1080×1920，30 帧/秒，约 2 分钟）：分镜、诗句字幕和配乐时间轴都写在 `timeline.mjs` 里。配乐全部用代码合成（`audio.mjs`：拨弦、梵钟、木鱼、磬、风声），不调用任何视频或音乐生成模型。

**下一支宣传片的配乐不要太舒缓**（用户 2026-11-18 的要求）：要有鼓点和节拍、往前推的旋律，寺院音色（木鱼、钟）只当节奏点用，不铺慢长音；镜头仍然不要切太快。

```bash
mkdir -p /tmp/sansa-promo/fonts   # 字体：Google Fonts 的 Zhi Mang Xing、Ma Shan Zheng（OFL）
curl -L -o /tmp/sansa-promo/fonts/ZhiMangXing-Regular.ttf https://raw.githubusercontent.com/google/fonts/main/ofl/zhimangxing/ZhiMangXing-Regular.ttf
curl -L -o /tmp/sansa-promo/fonts/MaShanZheng-Regular.ttf https://raw.githubusercontent.com/google/fonts/main/ofl/mashanzheng/MaShanZheng-Regular.ttf
npx vite --config tools/promo/vite.config.mjs          # 录制服务器，4327 端口
# 浏览器打开 http://127.0.0.1:4327/tools/promo/promo.html，等页面显示“完成”，帧在 /tmp/sansa-promo/shots
node tools/promo/audio.mjs /tmp/sansa-promo/score.wav
node tools/promo/assemble.mjs /tmp/sansa-promo/shots /tmp/sansa-promo/score.wav 宣传片.mp4
```

五个版本用 `cut` 参数切换（页面 `?cut=`，Node 脚本用环境变量 `CUT=`）：`vertical`（9:16，2 分钟，默认）、`short34`（3:4，约 1 分钟）、`explainer`（16:9 讲解视频）、`features`（9:16 功能介绍，约 2 分钟）、`news`（9:16「山寺上新」，约 1 分半）。

**山寺上新（`news`）**：咖啡馆（外景、露台、吧台、点单、请人喝）、祈福灯廊（走廊、挂灯、写心愿）、柿柿如意、键盘抄经、入夜，13 个镜头。
- 配乐用 `tools/promo/audio-news.mjs` 单独合成（`CUT=news node tools/promo/audio-news.mjs 配乐.wav`）：100 拍/分钟，底鼓、拍手、踩镲、沙锤、贝斯，古筝式拨弦奏主题，后半段加笛子；木鱼只当节奏点，梵钟只在片头片尾。
- 镜头每个 3 小节（7.2 秒，另加 0.5 秒叠化），起点都在小节线上；端出咖啡、递杯、灯离手、柿柿如意、每一组落墨都卡在拍子上（`timeline.mjs` 的 `EVENTS.n*`），配乐在同一拍发声。
- 界面截图 `uiCafeMenu.jpg`（点单菜单）、`uiWishWrite.jpg`（写心愿，选「上岸」、写「愿一战上岸，四月见分晓」）放进 `PROMO_UI`（默认 `/tmp/sansa-promo/ui`），浏览器 540×960、两倍像素。

**功能介绍（`features`）**：一天里走一遍寺院，17 个镜头每个 6～9 秒，镜头慢、底部字幕写功能名和一句玩法。
